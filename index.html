01 — Automation projects

Tools I build where PV work is slow, manual or error-prone.

Bookcase BY AADYA

Flagship · In active development

An AI-embedded pharmacovigilance case management platform. It takes ICSRs from source document to regulatory submission. AI is built into the system rather than added on: people review and curate data instead of typing it, and the final decision always stays with the user.

Source-to-case extraction

Literature and source documents are parsed and extracted into structured ICSR JSON. This covers multi-patient detection, splitting compound symptoms into discrete events, and switchable LLM providers (Claude / Groq).

Regulatory-grade data model

A field registry mapped to ICH E2B(R3), E2B(R2) and CIOMS, with one ID and one label per field. It includes MedDRA coding, IME flagging, labelledness assessment and a submission engine with per-health-authority profiles.

Multi-tenant & auditable

Each client company gets an isolated database and login-scoped access. Workflow stages follow real case-processing practice (Argus / Veeva-style), with assignment, versions and an immutable audit trail built for inspection readiness.

Agentic workflow — one orchestrator per open case

Intake (mail / upload)→ AE check→ Extraction→ Writer agents→ Duplicate check→ Case + validation→ Routing→ E2B submission
Layer 1 · ManualA full case-processing app that works on its own, with no AI involved.
Layer 2 · AI assistField-owning agents propose values and a person approves them. Human values are never overwritten.
Layer 3 · Full automationAgents run end to end. Steps are handed to them only once each agent passes its confidence threshold.

A shadow-learning loop runs sandboxed agents alongside the human on every case and compares their version with the user's. Each agent learns from the differences, using company conventions, SOPs and a hybrid graph + vector RAG.

Dataset · ML

ICSR training dataset for a domain LLM

A curated dataset of ICSRs extracted from PubMed/PMC open-access literature, in chat format for supervised fine-tuning. It is built to train an open-weight Qwen model with 4-bit QLoRA, with the goal of private, on-premise case extraction.

Agents · Claude

Multi-agent ICSR coding workflow

An end-to-end case assistant. It splits a reported verbatim into events, codes each event to MedDRA, flags Important Medical Events and assesses listedness against the product label.
