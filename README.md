# nikhilk197.github.io

Personal portfolio of Dr. Nikhil K: pharmacovigilance and PV automation.

## Publish on GitHub Pages
1. Sign in to GitHub as **nikhilk197** and create a new **public** repository named exactly `nikhilk197.github.io`.
2. Upload `index.html`, `Nikhil_K_CV.pdf` and this README (Add file → Upload files → Commit).
3. Go to Settings → Pages. Under Source, choose "Deploy from a branch" with `main` / `(root)`, then Save.
4. After 1–2 minutes the site is live at https://nikhilk197.github.io

Or from a terminal:
```
git init && git add . && git commit -m "Portfolio"
git branch -M main
git remote add origin https://github.com/nikhilk197/nikhilk197.github.io.git
git push -u origin main
```

To update, edit `index.html` and push again. To change the CV download, replace `Nikhil_K_CV.pdf`.
